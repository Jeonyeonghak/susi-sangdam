# 대입 지원 상담 앱 (강남한국학원 · DnA입시LAB)

담임이 학생 로우데이터를 넣고 → 통통통 2027 입결로 관심학과를 담고 → 판정·슬롯을 정해
학생별 **최종 지원 보고서를 바로 인쇄/PDF**로 뽑는 도구입니다. 스택은 STUDYHALL과 동일한
React(Vite) + Supabase + Vercel.

## 화면 흐름
1. **① 학생 로우데이터** — 담임 선택 후 학생을 하나씩 추가하거나 CSV 붙여넣기로 일괄 등록. 내신·계열·희망진로·메모.
2. **② 관심학과 담기** — 대학/학과/지역/전형유형/계열로 입결 검색. `내신 이내만` 체크 시 학생 내신으로 붙을 만한 곳만. [담기]로 오른쪽 보드에 적재되고, 학생 내신 대비 컷으로 **안정/적정/도전/상향이 자동 제안**됩니다. 판정·상태(관심/지원확정/보류/제외)·슬롯·사유를 그 자리에서 수정.
3. **③ 최종 지원 보고서** — 담긴 학과가 판정순으로 정리되고 [인쇄/PDF 저장]으로 A4 가로 출력.

> Supabase를 아직 안 붙였어도 브라우저 로컬 저장 + 데모 입결(주요대 일부)로 바로 시험됩니다.

## 준비 (한 번만)

### 1) Supabase
- STUDYHALL 프로젝트에 같이 붙여도 되고 새 프로젝트도 됩니다.
- **SQL Editor**에 `supabase_schema.sql` 전체를 붙여넣고 실행.
- **Table Editor > admissions > Import data > CSV**로 `admissions.csv`(26,410행) 업로드.
  컬럼이 자동 매핑됩니다. `id`가 PK이니 그대로 두세요.

### 2) 환경변수
`.env.example`을 `.env`로 복사하고 값 채우기 (Settings > API):
    VITE_SUPABASE_URL=...
    VITE_SUPABASE_ANON_KEY=...

### 3) 실행 / 배포
    npm install
    npm run dev      # 로컬
    npm run build    # 배포 빌드
Vercel: 이 폴더를 GitHub에 올리고 Import → 환경변수 2개 등록 → Deploy.

## 데이터 갱신
매년 새 통통통 파일이 나오면 같은 컬럼 구조로 CSV를 만들어 admissions 테이블을 교체하면 됩니다.

## 판정 로직 (참고)
학생 내신(전과목) 대비 26컷(등급): 여유 +0.4↑ 안정 · +0.4~-0.1 적정 · -0.1~-0.5 도전 · 그 이하 상향.
수치는 담임이 언제든 드롭다운으로 덮어쓸 수 있습니다.

## 주의
입결(등급)은 통통통 자료 기준 참고값입니다. 대학 공식 발표와 다를 수 있으니 최종 판단은 검토 후 확정하세요.
